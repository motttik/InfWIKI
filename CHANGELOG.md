# Changelog

Все изменения в проекте InfWIKI.

Формат ведётся согласно [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [3.0.0] — 2024-02-24

### ✨ Добавлено (Все функции из Roadmap реализованы!)

#### 🌐 Веб-интерфейс
- **PWA (Progressive Web App)** — установка как приложение
- **Service Worker** — офлайн-режим, кэширование
- **App Manifest** — иконки, метаданные
- **Push-уведомления** — уведомления о новых статьях

#### 📱 Мобильные возможности
- **Адаптивный дизайн** — мобильная и планшетная версии
- **Тач-жесты** — свайпы для навигации
- **Голосовой ввод** — поиск статей голосом (ru/en)

#### 🏷️ Категоризация
- **8 категорий** — Наука, Технологии, История, Культура...
- **Теги** — пользовательские теги для тем
- **Автоматическая категоризация** — AI-классификация тем

#### 📄 Экспорт
- **PDF экспорт** — печать и сохранение в PDF
- **Markdown экспорт** — .md файлы
- **Копирование в буфер** — быстрый копипаст

#### 📊 Статистика
- **Трекинг просмотров** — счётчик статей
- **Аналитика поисков** — статистика запросов
- **Стрики** — дни подряд в приложении
- **Популярные темы** — топ просматриваемых тем

#### 🔔 Уведомления
- **Push API** — браузерные уведомления
- **Уведомления о новых статьях**
- **Совет дня**

#### ♿ Доступность
- **ARIA атрибуты** — доступность для скринридеров
- **Поддержка клавиатуры** — горячие клавиши
- **Контрастность** — WCAG совместимость

### 🛠️ Улучшено

- Полная переработка архитектуры
- TypeScript строгая типизация
- i18n локализация (ru/en)
- 3 темы оформления (Light, Dark, Cyberpunk)
- История навигации
- Избранное с экспортом

### 📦 Инфраструктура

- Docker (production + development)
- GitHub Actions CI/CD
- Vitest тесты (18+)
- ESLint + TypeScript

### 🗑️ Удалено

- Roadmap (все функции реализованы!)
- Устаревшая структура проекта
- Python код (полный переход на React/TypeScript)

---

## [2.0.0] - 2024-02-24

### ✨ Добавлено

- **Полная локализация** на русский и английский языки
- **Три темы оформления**: Светлая, Тёмная, Киберпанк
- **История навигации** с кнопками назад/вперёд
- **Избранное** с экспортом/импортом закладок
- **Новая архитектура проекта** с правильной структурой папок
- **TypeScript типы** для всех компонентов и функций
- **Кастомные хуки**: useTheme, useBookmarks, useNavigationHistory, useWiki
- **UI компоненты**: Button, Input, SearchBar, Header, Footer
- **Docker поддержка** для production и development
- **GitHub Actions** для CI/CD
- **Тесты** на Vitest + React Testing Library
- **Красивый README.md** с полной документацией
- **CONTRIBUTING.md** для контрибьюторов
- **LICENSE** (MIT)

### 🛠️ Изменено

- Обновлён React до версии 19.1.0
- Улучшена структура проекта для масштабируемости
- Оптимизирована генерация ASCII-арта
- Улучшена обработка ошибок API
- Обновлены зависимости до актуальных версий

### 🐛 Исправлено

- Утечки памяти при отмене запросов
- Проблемы с кодировкой кириллицы
- Ошибки типов TypeScript

### 🗑️ Удалено

- Устаревшие файлы metadata.json
- Прямые импорты из старых папок
