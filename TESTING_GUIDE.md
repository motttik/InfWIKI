## 🐛 Отладка проблем

### Проблема: Белый экран

**Причины**:
1. JavaScript ошибка в консоли
2. Не загрузился i18n
3. Пустой localStorage

**Решение**:
```bash
# Очистить кэш
rm -rf node_modules/.vite
npm run dev
```

### Проблема: "GEMINI_API_KEY is not configured"

**Это нормально!** Приложение работает в демо-режиме.

Для использования реального API:
```bash
# Создать .env
cp .env.example .env

# Редактировать .env
echo "GEMINI_API_KEY=ваш_ключ" >> .env

# Перезапустить
npm run dev
```

### Проблема: Порт 3000 занят

```bash
# Найти процесс
lsof -i :3000

# Убить процесс
kill -9 <PID>

# Или изменить порт в vite.config.ts
```
